# 법률사무소 백신 랜딩페이지

HTML, CSS, jQuery 3.7.1로 구성한 반응형 정적 페이지입니다. jQuery는 vendor에 포함되어 패키지 설치 없이 실행됩니다.

## 실행

```sh
cd /workspace/vcfsyk
python3 -m http.server 3000 --bind 0.0.0.0
```

단계별 진단 폼, 입력 검증, FAQ, 개인정보 안내 모달, 상담 영역 진입 시 숨겨지는 하단 CTA를 제공합니다.

## 게시 전 준비

현재 폼은 시연용으로, 데이터를 전송하거나 저장하지 않습니다. 접수 서버와 개인정보 처리 방침을 연결하고, 법률사무소의 신원·연락처·변호사 이력·기관 자문 사실을 확인한 뒤 게시하세요. 감면 예시는 법원 결과를 보장하지 않습니다. 변호사 사진은 제공되지 않아 건축적 일러스트로 구성했습니다.

Google Fonts 연결이 안 되면 시스템 sans-serif 글꼴로 표시됩니다.
